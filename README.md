# Bourke Construction — speculative website redesign

A **Novenworks** concept homepage and site for [Bourke Construction Inc.](https://www.bourkeconstructionoc.com/), an Orange County residential remodeling contractor based in Anaheim and Laguna Beach.

**Bourke Construction is not a Novenworks client.** This was built unsolicited as a speculative demonstration. Business marks, Houzz badges, and project photography remain the property of their owners.

**Live demo:** [bourke-construction-demo.vercel.app](https://bourke-construction-demo.vercel.app)  
**Repo:** [Novenworks/Bourke-Construction-Demo](https://github.com/Novenworks/Bourke-Construction-Demo)



An editorial, photography-first presentation of the company that already exists:

- Serving Orange County since 1996
- Family-owned (Ed Bourke; Patrick Bourke, project manager)
- CA CSLB license **#717199**, B — General Building, verified current and active
- Best of Houzz Service award, 2026, eleven-year streak (first-party)
- Real kitchens, baths, ADUs, additions, and the Laguna Beach Azek deck

## Local setup

```bash
npm install
npm run dev
```

The app is a TanStack Start (Vite) project. Production build:

```bash
npm run build
npm run preview
```

## Pages

- `/` homepage
- `/work` project gallery (first-party photos)
- `/services` kitchens, baths, additions, ADUs, decks, remodeling
- `/process` consultation → estimate → contract → build → walkthrough
- `/about` team + license
- `/contact` estimate form (**demo — does not email the company**)
- `/outreach` operator brief, unlinked, `noindex`
